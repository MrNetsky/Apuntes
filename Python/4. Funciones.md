Una función es un **bloque de código al que le damos un nombre para poder ejecutarlo cuando lo necesitemos**. Esto tiene dos ventajas principales:

- Podemos **dividir un programa en partes más pequeñas**, facilitando su lectura y mantenimiento.
- Podemos **reutilizar código** sin tener que escribirlo nuevamente.

Para definir una función usamos la palabra clave `def`, seguida del nombre de la función y, entre paréntesis, sus **parámetros**. A continuación se escribe, mediante indentación, el bloque de código que pertenece a la función. 

Definir una función **no ejecuta su código**. Para ejecutar una función debemos **llamarla**, utilizando su nombre seguido de los argumentos entre paréntesis.

Los argumentos se asocian normalmente con los parámetros en el orden en que aparecen, aunque también podemos indicar explícitamente el nombre del parámetro.

Al llamar a una función, debemos proporcionar argumentos para todos sus parámetros obligatorios. Si faltan argumentos obligatorios o se proporcionan argumentos que la función no puede aceptar, Python generará un `TypeError`.
```python
def saludo(nombre, apellido):
	"""Esto es un docstring. Es una cadena de texto ubicada como primera instrucción dentro de una función, que se utiliza para documentar qué hace y cómo utilizarla."""
	print('Tu nombre es:', nombre)
	print('Y tu apellido es:', apellido)
	
saludo('Pablo', 'Acosta Cuestas') 
#saludo(apellido='Acosta Cuestas', nombre='Pablo') 

""" 
Ambas dan el siguiente resultado:
Tu nombre es: Pablo
Y tu apellido es: Acosta Cuestas 
"""
```
Es posible asignar un **valor por defecto** a un parámetro. En ese caso, se utilizará dicho valor si al llamar a la función no proporcionamos un argumento para ese parámetro.
```python
def saludar(nombre, veces=1):
    for _ in range(veces):
        print("Hola", nombre)
        
saludar("Pablo") # Hola Pablo
saludar("Pablo", 2) 
#Hola Pablo
#Hola Pablo
```

## `*args` y `**kwargs`
`*args` permite que una función reciba **una cantidad variable de argumentos posicionales**. Todos los argumentos posicionales recibidos se agrupan en una **tupla**. Y como `args` es una tupla, podemos recorrerla:
```python
def mostrar(*args):
    for elemento in args:
        print(elemento)

mostrar(10, 20, 30)
```
En realidad, **`args` no es una palabra reservada de Python**. Pero existe una convención muy extendida. Por eso es recomendable utilizar ese nombre cuando estamos siguiendo la convención habitual. Lo importante es el `*`.

`**kwargs` permite recibir una cantidad variable de **argumentos con nombre**. Todos los argumentos con nombre recibidos se agrupan en un **diccionario**.
```python
def presentar(**kwargs):
    print(kwargs)
    
presentar(nombre="Pablo", edad=29)
```

Incluso puedo juntar a los dos como parámetros de una misma función:
```python
def ejemplo(*args, **kwargs):
    print(args)
    print(kwargs)

ejemplo(10, 20, 30, nombre="Pablo", edad=29)
```
## Métodos, sentencias y funciones Built-in
Los **métodos** son operaciones asociadas a un objeto y normalmente se invocan mediante el operador `.`.
Las **sentencias** son instrucciones que forman parte de la sintaxis lenguaje.
Las **funciones built-in** son funciones que vienen incorporadas con Python; no es necesario definirlas ni importarlas para utilizarlas.
```python
def procesar_nombre(nombre):
    nombre = nombre.strip()       # Método
    print("Nombre:", nombre)      # Función built-in
    return nombre                 # Sentencia

resultado = procesar_nombre("  Pablo  ")
print(resultado)
```
`print()` es una función _built-in_ cuya finalidad es mostrar información. `return` es una sentencia que termina la ejecución de una función y devuelve un valor al código que la llamó. Ese valor puede ser asignado a una variable, utilizado directamente en una expresión o pasado a otra función.
