## Condicionales

Permiten que un programa tome diferentes caminos dependiendo de si se cumple o no una condición. Comienzan con `if`, seguido de una condición y dos puntos `:`. Si la condición se evalúa como verdadera, se ejecuta el bloque de código indentado que se encuentra a continuación. Si la condición no se cumple, podemos utilizar `elif` para comprobar otra condición, o `else` para ejecutar un bloque cuando ninguna de las condiciones anteriores se cumple. Los bloques de código se delimitan mediante **indentación**.
```python
numero = 29
if número > 0:
	print('Positivo')
elif numero < 0:
	print('Negativo')
else:
	print('Cero')
```
También hay otra manera de estructurarlo (A if C else B):
```Python
edad = int(input("Ingresa tu edad: ")) 
resultado = "Mayor de edad." if edad >= 18 else "Menor de edad."

print(resultado)
```
La función `input()` permite al usuario ingresar un dato. Devuelve ese dato como una cadena (`str`). `int()` permite convertirlo a un número entero.
## Bucles

A diferencia del anterior, nos permite repetir un bloque de código mientras se cumpla una determinada condición o durante una cantidad determinada de iteraciones. Lo que nos ahorra la tarea de escribir líneas extra de código, pero a su vez también suelen ser muy útiles para validar datos.
### while

`while` permite repetir un bloque de código **mientras una condición sea verdadera**.
La condición se evalúa **antes de cada iteración**. Por eso, si desde el comienzo es falsa, el bloque puede ejecutarse **cero veces**.
```python
i = 1 # Contador.
while i <= 10:
	print('2 x', i, '=', 2 * i) # IMPORTANTE separar con ',' porque print() acepta múltiples argumentos separados por comas.
	i = i + 1
print('Esta es la tabla del 2') # Cuando el contador deje de cumplir con la condición se ejecutará esta línea de código.
```

`break` permite **interrumpir inmediatamente el bucle**, aunque su condición todavía sea verdadera.

Esto resulta especialmente útil cuando no sabemos de antemano cuántas veces tendremos que repetir una operación y queremos establecer una condición que determine cuándo salir.
```python
while True:
entrada = input(“> “)
	if entrada == “adios”:
		break
	else:
		print entrada
```

`continue` permite **saltar el resto del código de la iteración actual y pasar directamente a la siguiente iteración del bucle**.
```python
edad = 0
while edad < 29:
	edad = edad + 1
	if edad != 29:
		continue 
	print('Felicidades, tienes ' + str(edad))
```

### `for`

Se utiliza para **iterar sobre los elementos de un objeto iterable**, ejecutando un bloque de código una vez por cada elemento.

En cada iteración, una variable recibe el elemento actual. Esta variable puede tener cualquier nombre y existe principalmente para poder trabajar con el elemento durante esa iteración.

Por ejemplo:

```python
