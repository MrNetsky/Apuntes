Listado de instrucciones entendibles a un computador y que se ajusta a las reglas sintácticas de un lenguaje de programación (Python, JavaScript, C, etc). 

Un algoritmo que cumpla con estas reglas se llamará [[Programa]].

Para escribir un programa nos valemos de un editor de texto (NeoVim, VSC, etc.), a este proceso se lo conoce como digitación.

Una vez que terminamos de digitar un programa, el computador revisa que el éste que se ajuste a las reglas sintácticas de un determinado lenguaje de programación. A este proceso se lo denomina como [[Compilación]]. Este proceso evaluar dos tipos de errores:
- Sintaxis
- Precaución

Es importante saber que así como existen diferentes idiomas, también existen diferentes compiladores para los mismos. 

Pero existe un 3er tipo de error, el cual el compilador no detectará y son los errores lógicos. Esto es porque el programa no discutirá sobre lo que quieres hacer y cómo quieres hacerlo. Sin embargo son detectados en la prueba de escritorio.

*¿Y si en la prueba de escritorio no se alcanza el objetivo?* Pueden pasar las siguientes cuestiones:
- No estaba claro el objetivo, por ende fallamos en todo el proceso.
- No realizamos bien la prueba de escritorio y creímos que el algoritmo estaba bien.
- No hicimos una buena transcripción y el programa terminó siendo una representación técnica diferente del algoritmo inicial.
